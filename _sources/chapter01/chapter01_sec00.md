# 1. Aussagenlogik

Mathematik ist eine strukturierte Art des Denkens. Wir gehen von Annahmen aus und ziehen daraus Schritt für Schritt logische Schlüsse. Jeder Schluss führt zu einer neuen Aussage, die wieder Ausgangspunkt für den nächsten Schluss sein kann. So entsteht eine Kette von Schlüssen, an deren Ende ein Ergebnis steht.

Ein solches Ergebnis ist nur so verlässlich wie die Kette, die zu ihm führt. Deshalb muss man in einer mathematischen Argumentation jederzeit beides überprüfen können: ob die Annahmen richtig sind, von denen wir ausgehen, und ob jeder einzelne Schluss in der Kette richtig ist. Ist auch nur ein Glied falsch, ist das Ergebnis nicht gesichert.

Die Aussagenlogik liefert die Regeln für diese Prüfung. Sie legt fest, was eine Aussage ist, wie man Aussagen miteinander verknüpft und wann ein Schluss von einer Aussage auf eine andere richtig ist.
